One CLI for the daily chores

Pick a flavor, build, ship. Missing arguments are asked for, not rejected.
flutter build apk --release --flavor staging -t lib/main_staging.dart
by hand: copy .env, run build_runner, remember the flags
➜
moshaf_boilerplate build apk staging
env step + build, flags filled in for you
1create
Once per project. Asks for a name, builds the whole app.
$ moshaf_boilerplate create
project name: my_app
display name: My App
✔ Project ready
2env
Switch flavor: copies .env + Firebase files, runs build_runner.
$ moshaf_boilerplate env
Select flavor:
  1. dev
❯ 2. staging
  3. prod
3build
apk, aab or ipa, with versioning and ipa export options.
$ moshaf_boilerplate build ipa prod \
  --bump patch
1.2.3+4 → 1.2.4+5
✔ saved to pubspec
4assets · flavor
Housekeeping as the project grows.
$ moshaf_boilerplate assets
$ moshaf_boilerplate flavor add qa
$ moshaf_boilerplate flavor list
dev · staging · prod · qa
Run it from the projectenv, build, assets and flavor run in your generated project's root, not where you ran create.
No terminal, no promptsIn CI or piped input nothing is asked, so pass every argument. env takes --yes, and build takes --dry-run to preview.
